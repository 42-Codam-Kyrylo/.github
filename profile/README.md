# 🧠 42 Codam Projects

Welcome to my **Codam (42 Network)** project collection!  
Each repository here represents a project from the **42 curriculum**.

---

## 🚀 Projects Roadmap

### Milestone 0
- [x] [**Libft**](https://github.com/42-Codam-Kyrylo/libft) - Create a foundational C library reimplementing standard libc functions along with additional utility and linked list functions.

### Milestone 1
- [x] [**push_swap**](https://github.com/42-Codam-Kyrylo/push_swap) - Write an algorithmic C program that sorts integers across two stacks using a restricted set of operations in the minimum number of moves.
- [x] [**get_next_line**](https://github.com/42-Codam-Kyrylo/get_next_line) - Develop a C function that reads and returns a single line at a time from a file descriptor using static variables.
- [x] [**ft_printf**](https://github.com/42-Codam-Kyrylo/ft_printf) - Reimplement the standard C library printf function to format and print various data types using variadic arguments.

### Milestone 2
- [x] [**Born2beroot**](https://github.com/42-Codam-Kyrylo/Born2beroot) - System administration and virtualization.
- [x] [**A-Maze-ing**](https://github.com/42-Codam-Kyrylo/A-Maze-ing) - Build a modular Python maze generator and visualizer that generates both perfect and Pac-Man-style mazes with shortest path solutions based on a configuration file.
- [x] [**Python Module 00**](https://github.com/42-Codam-Kyrylo/Python-Module-00) - Learn Python fundamentals, including basic syntax, variables, arithmetic operations, conditionals, loops, recursion, and type annotations, through a series of community-garden-themed exercises.
- [x] [**Python Module 01**](https://github.com/42-Codam-Kyrylo/Python-Module-01) - Develop an object-oriented Python system modeling a digital garden ecosystem, covering concepts such as class creation, methods, encapsulation, inheritance, method overriding, and static/class methods.
- [x] [**Python Module 02**](https://github.com/42-Codam-Kyrylo/Python-Module-02) - Build resilient agricultural data pipelines and monitoring systems by mastering Python exception handling and custom exception hierarchies.
- [x] [**Python Module 03**](https://github.com/42-Codam-Kyrylo/Python-Module-03) - Master Python collections and data structures—including lists, tuples, sets, dictionaries, generators, and comprehensions—by building components for a game analytics platform.
- [x] [**Python Module 04**](https://github.com/42-Codam-Kyrylo/Python-Module-04) - Master file operations, standard stream management, and context managers to build a secure digital archiving system.
- [x] [**Python Module 05**](https://github.com/42-Codam-Kyrylo/Python-Module-05) - Build an adaptive data processing pipeline utilizing abstract base classes, inheritance hierarchies, subtype polymorphism, and protocol plugins.
- [x] [**Python Module 06**](https://github.com/42-Codam-Kyrylo/Python-Module-06) - Explore Python's module and package import system by building an alchemical laboratory package that manages relative and absolute imports and resolves circular dependencies.
- [x] [**Python Module 07**](https://github.com/42-Codam-Kyrylo/Python-Module-07) - Master object-oriented design patterns such as abstract factories, capability interfaces, and strategy patterns by implementing a modular creature card game and tournament system.
- [x] [**Python Module 08**](https://github.com/42-Codam-Kyrylo/Python-Module-08) - Learn fundamental data engineering workflows by managing Python virtual environments, handling package dependencies with pip and Poetry, and configuring environment variables securely.
- [x] [**Python Module 09**](https://github.com/42-Codam-Kyrylo/Python-Module-09) - Master data validation and schema definition using Pydantic v2 by creating models with field constraints, custom validators, and nested structures for space-themed datasets.
- [x] [**Python Module 10**](https://github.com/42-Codam-Kyrylo/Python-Module-10) - Master functional programming concepts in Python by utilizing lambda expressions, higher-order functions, closures, functools utilities, and custom decorators.

### Milestone 3
- [x] [**Codexion**](https://github.com/42-Codam-Kyrylo/Codexion) - Implement a multi-threaded concurrency simulation in C using POSIX threads, mutexes, condition variables, and custom priority queue scheduling (FIFO/EDF) to manage resource competition among coders and prevent deadlock and burnout.
- [ ] 🚧 [**Call Me Maybe**](https://github.com/42-Codam-Kyrylo/call-me-maybe) (*In progress*) - Build a Python function-calling tool that translates natural language prompts into valid, schema-compliant JSON function calls using constrained decoding with a small language model.
- [x] [**Fly-in**](https://github.com/42-Codam-Kyrylo/Fly-in) - Design and simulate an object-oriented drone routing system in Python that moves multiple drones across a constrained network graph from a start zone to an end zone in the minimum number of simulation turns.

### Milestone 4
- [ ] [**NetPractice**](https://github.com/42-Codam-Kyrylo/NetPractice) - Learn the fundamentals of computer networking by completing ten simulated network configuration exercises involving IP addressing, subnet masks, and default gateways.
- [ ] [**Pac-Man**](https://github.com/42-Codam-Kyrylo/Pac-Man) - Develop a complete, playable Pac-Man arcade game in Python featuring custom JSON configuration, external maze generator integration, autonomous ghost behaviors, and a persistent highscore system.
- [ ] [**RAG against the machine**](https://github.com/42-Codam-Kyrylo/RAG-against-the-machine) - Build a Retrieval-Augmented Generation (RAG) system that indexes code and documentation using lexical retrieval methods and uses a local language model to answer queries grounded in the codebase.

### Milestone 5
- [ ] [**Inception**](https://github.com/42-Codam-Kyrylo/Inception) - Set up a multi-service infrastructure in a virtual machine using Docker Compose, creating custom container images for NGINX with TLS, WordPress with PHP-FPM, and MariaDB with persistent volumes.
- [ ] [**The Answear Protocol**](https://github.com/42-Codam-Kyrylo/The-Answear-Protocol) - Build a multiplayer retro text adventure featuring a line-based TCP server adhering to the RFC 42TAP specification alongside both a CLI client and a GUI client.
- [ ] [**Agent Smith**](https://github.com/42-Codam-Kyrylo/Agent-Smith) - Build an autonomous agentic framework that solves coding challenges by reasoning, generating executable Python code, and interacting with tools in a secure sandbox.

### Milestone 6
- [ ] [**ft_transcendence**](https://github.com/42-Codam-Kyrylo/ft_transcendence) - Develop a full-stack, real-time web application as a team featuring multi-user support, authentication, containerized deployment, and selectable modules such as games and chat.
